# AppSneak Clone

A clone of the AppSneak.com website built with Next.js, React, and Tailwind CSS.

## Features

- Responsive design matching the original AppSneak.com website
- App grid with search functionality
- Detailed app pages with animated step-by-step process
- Dark theme UI with modern components

## Tech Stack

- **Framework**: Next.js 15
- **UI Components**: Shadcn UI
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Package Manager**: Bun

## Getting Started

First, install the dependencies:

```bash
bun install
```

Then, run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- **Home Page**: Grid of app cards with search functionality
- **App Detail Page**: Individual app page with generator steps
